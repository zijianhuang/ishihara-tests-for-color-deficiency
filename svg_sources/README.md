# Customized 38-Plate Files

Martin Krywinski has published https://mk.bcgsc.ca/ishihara-tests-for-colour-deficiency/downloads/ishihara-tests-for-color-deficiency-hires-v1.0.0.zip

And the unzipped content are mirrored on https://github.com/zijianhuang/ishihara-tests-for-color-deficiency/tree/main/svg_sources

The files here are based on what in folder SVG, with modifications and extensions, for the sake of scaling / responsive design in Progressive Web App.

## Modifications to Original SVG File
The modifications are done through simple text and regex replacement using Notepad++.

### SVG viewport

```xml
<svg height="2419" width="2419" xmlns="http://www.w3.org/2000/svg" xmlns:svg="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink">
```
to
```xml
<svg height="2419" width="2419" viewBox="200 200 2019 2019" xmlns="http://www.w3.org/2000/svg" xmlns:svg="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink">
```

### xlink:href to low resolution PNG.

```xml
<image height="2419" width="2419" x="0" xlink:href="../hires/ishihara-38-test-plates-2.png" y="0" />
```
to
```xml
<image height="2419" width="2419" viewBox="200 200 2019 2019" x="0" xlink:href="../lowres/ishihara-38-test-plates-2.png" y="0" />
````

Each high resolution PNG file is around 10 MB, this makes the 2-round rendering of the plate look not nice, since there's a significant lap between the rendering of SVG and the rendering PNG on many day to day computing devices. Linking to a low resolution PNG file makes the rendering look instant in almost all cases. And also make the automatic caching of service worker of PWA work more reliable.

### Circle clip

Rather than displaying the whole rectangle of the PNG, circle clipping is to focus on the core part of the Ishihara plates.

```xml
	<defs>
		<clipPath id="circleClip">
			<circle cx="1209.5" cy="1209.5" r="986"/>
		</clipPath>
	</defs>
	<g clip-path="url(#circleClip)">
```

**Remarks:**
* It is possible to clip in the traditional Ishihara plate style.
* And this could be done through modifying the file, or modifying the SVG content during runtime when the app may load the content asynchronously, so the users may choose 2 different styles of clipping.

### Extension files to the plates

To make user friendly UI, SVG files with "black" lines describing the patterns that the test subjects could see are generated by AI engines. This is a kind of reverse engineering.

### Make sure the fill color i currentColor rather than black

This will make the these SVG files are adapting well the light and the dark themes.

Examples:
```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 500 500" width="500" height="500" >
  <circle cx="195.7" cy="247.6" r="10.3" fill="currentColor"/>
  <circle cx="266.4" cy="363.0" r="9.9" fill="currentColor"/>
```
or
```xml

```<svg
   fill="currentColor"
   version="1.1"
```

**Remarks:**
* If Martin had crafted the SVG files with drafts for the patterns in mono color, those drafts will be the most perfect.
