The Ishihara test is a color vision test for detection of red–green color deficiencies. It consists of a series of Ishihara plates, which are a type of pseudoisochromatic plate.

This app provides several sets of Ishihara and Ishihara-inspired plates, which may be presented either sequentially or in random order. For each plate, the test subject tries to identify the number or pattern (such as a line) hidden within the image. Responses are recorded by selecting the appropriate button from a group of options, one of which corresponds to the perceived figure.
