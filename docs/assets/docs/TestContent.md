# Preparation of Ishihara Plates

Basically you need to select a range of SVG files presenting patterns like letter, digit and shape etc., then transform them to various styles of Ishihara plates.

## SVG Files

You can use a SVG editor to create the initial patterns, or you can download some free SVG files or purchase.

### Free SVG Files

1. [Material Symbols](https://fonts.google.com/icons?icon.set=Material+Symbols)
2. [Material Icons](https://fonts.google.com/icons?icon.set=Material+Icons)
3. [SVG Repo](https://www.svgrepo.com/)
4. [Hero Icons](https://heroicons.com/)
5. [Tabler's open source icons](https://tabler.io/icons)
6. [Phosphor](https://phosphoricons.com/)
7. [Bootstrap](https://icons.getbootstrap.com/)

Remarks:
* Please do check the license agreement or Terms of Service of these resources.

### Free SVG Editor

* [Inkscape](https://www.svgrepo.com/)

Remarks:
* Please direct your questions to [Inkscape Community](https://inkscape.org/community/) or AI.

## Ishihara Plate Generator

[Ishihara Plate Generator](https://franciscouzo.github.io/ishihara/) takes a SVG file and generate Ishihara plate.
